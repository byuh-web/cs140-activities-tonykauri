Questions & Answers

What is normal flow in HTML?
Normal flow is the default way elements appear on a webpage. Block elements stack vertically, and inline elements appear side by side.

What does float do? Why do you need to clear the float?
Float moves an element to the left or right and allows text to wrap around it. You need to clear the float so that elements below it do not wrap around it unintentionally.

What do absolute, fixed, and relative do?
Relative positioning moves an element from its normal position. Absolute positioning places an element relative to its nearest positioned ancestor. Fixed positioning keeps an element in the same place even when scrolling.
